# Axiom MCP 0.1.5

## New Features

- Add installation commands to `graph_version`: identify `axm` and `axiom-cli`, show version/doctor/update/removal commands and provide the installation/update URLs.
- Keep `graph_version` read-only; it reports commands without installing or updating software.

Full Changelog: [v0.1.4…v0.1.5](https://github.com/orchex006/axiom-mcp/compare/v0.1.4...v0.1.5)

## Installation

Download the portable wheel and verify its SHA-256 against `SHA256SUMS`, then install it in a Python 3.13 virtual environment:

```sh
python -m pip install axiom_mcp-0.1.5-py3-none-any.whl
```

Configure stdio or Streamable HTTP with registered credential references. Tool discovery alone does not establish authenticated graph access.

See the [installation guide](https://github.com/orchex006/axiom-mcp/blob/main/docs/install-and-upgrade.md) and [tool reference](https://github.com/orchex006/axiom-mcp/blob/main/docs/reference/mcp.md).
